## 重要结论
- E1：v3 比 Baseline 提升 20.35% 吞吐，Prefill 轮数减少 25%。
- E2：v3 比 v2 避免 1 次 medium 请求抢占、47 个 Prefill Token 重计算，吞吐提升 4.62%；但 v3 吞吐比 Baseline 低 5.86%，Owner 延迟变差。

- E1/E2 是定向人工构造实验，不能把专项收益宣称为所有负载通用收益。
